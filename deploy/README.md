# BeMusic — free Azure deployment (no Docker)

Deploy this Laravel 12 + React app as a native **LEMP stack on a single free
Azure Linux VM** (`Standard_B2ats_v2`, ARM, 2 vCPU / 4 GB — included in the
Free Services allowance of 750 VM-hours/month).

What is shipped vs built on the server:

| Component            | Where it comes from                                   |
|----------------------|-------------------------------------------------------|
| Front-end (`public/build`, 537 assets + manifest + service worker) | pre-built and included |
| PHP dependencies     | `vendor/` included (pure-PHP, no Composer needed on VM) |
| `.env`               | generated by `setup.sh`                                 |
| Database             | MariaDB, created by `setup.sh`                          |
| Cache / queue        | Redis (native), configured by `setup.sh`                |
| Queue worker         | systemd unit, installed by `setup.sh`                   |
| Web sockets          | disabled (`BROADCAST_CONNECTION=log`) — free infra      |
| Search               | Meilisearch (local service on 127.0.0.1:7700, installed by `setup.sh`) |

---

## 1. Provision the free VM

Via Azure CLI (or the Portal → *Free services* → VM + use a B2ats v2):

```bash
az login

az group create -n bemusic-rg -l swedencentral

# In this region Standard_B2ats_v2 is provisioned as x64, so use the x64 image.
az vm create \
  -g bemusic-rg -n bemusic \
  --image Canonical:ubuntu-24_04-lts:server:latest \
  --size Standard_B2ats_v2 \
  --authentication-type ssh --admin-username azureuser --generate-ssh-keys \
  --public-ip-sku Standard --public-ip-address-allocation static \
  --os-disk-size-gb 30 --storage-sku Standard_LRS

az vm open-port -g bemusic-rg -n bemusic --port 80       # and 443 if using HTTPS
az vm show -g bemusic-rg -n bemusic -d --query publicIps -o tsv
```

> Keep the VM running under 750 h/month to stay free. Stop it when unused:
> `az vm deallocate -g bemusic-rg -n bemusic` (start again with `az vm start`).
> Verify disk is Standard HDD/SD in the free-eligibility terms for your region.

## 2. Upload and extract

Run from your machine (replace IP and archive name as needed):

```bash
scp bemusic-deploy.zip azureuser@<ip>:~/

ssh azureuser@<ip>
sudo apt-get install -y unzip
sudo mkdir -p /var/www
sudo unzip -q ~/bemusic-deploy.zip -d /var/www    # extracts to /var/www/bemusic
sudo bash /var/www/bemusic/deploy/setup.sh        # no args → http://<ip>
```

To use a domain instead, pass it: `sudo bash .../setup.sh https://music.example.com`

## 3. Finish via the built-in web installer

1. Open `http://<ip>/install`
2. DB form is prefilled — the password was printed at the end of `setup.sh`.
3. Create the admin account; the installer migrates, seeds, and finalizes.

## 4. Optional hardening

```bash
# HTTPS with Let's Encrypt (needs a domain + DNS A record → this VM)
sudo apt-get install -y certbot python3-certbot-nginx
sudo certbot --nginx -d music.example.com
```

- Mail is set to `MAIL_MAILER=log`. Point it at a real SMTP provider before
  enabling signups/notifications.
- After install you may cache configs for speed:
  `sudo -u www-data php /var/www/bemusic/artisan optimize`

## API keys (production)

Configured in `.env` (on the box + in `env.production`):

| Service | Where | Status |
|---------|-------|--------|
| Spotify (import/metadata) | `.env` `SPOTIFY_ID` / `SPOTIFY_SECRET` | set |
| Last.fm (charts/lookups) | `.env` `LASTFM_API_KEY` | set |
| YouTube (auto video source) | Admin → Settings → Player → "YouTube API key" (data-api key, stored in DB) | pending |

OAuth (Google/Twitter/Facebook) and billing (Stripe/PayPal) are optional and
stay disabled until you add the credentials and switch `BILLING_ENABLED`.

## Running the app on the box

- Web: `systemctl status nginx php8.3-fpm`
- Queue worker: `systemctl status bemusic-queue` — runs **Laravel Horizon**
  (single worker, no auto-scale, tuned for the free VM). Status dashboard at
  `http://<ip>/horizon` (admins only; `app/Providers/HorizonServiceProvider.php`
  gates it to users with the `admin` permission).
- Scheduler cron runs `php artisan schedule:run` every minute (`crontab -l -u www-data`).
- Logs: `/var/log/nginx/bemusic*.log`, `journalctl -u bemusic-queue -f`,
  `/var/www/bemusic/storage/logs/laravel.log`

## Rebuilding the front-end later (optional)

The bundle includes the pre-built assets. If you ever want to rebuild from
source (e.g. after pulling new commits):

```bash
# npm registry is unreliably slow in some regions; npmmirror is faster
npm ci --registry=https://registry.npmmirror.com --network-concurrency=4 --fetch-retries=10
npm run build
```

Note: `npm run build` runs `tsc --skipLibCheck` first, which currently fails on
TypeScript 7 strictness against this codebase. To build only the Vite bundle:

```bash
npx vite build
```
