Keekii — palette options

Three revisions of “Ember & Ink” with the violet removed. Swatches are real sRGB values converted from oklch, and the ratios below are computed WCAG 2.1 contrast (not eyeballed). Each option is shown in a light and dark variant in a small player mock, so the pairing can be judged in context. Nothing in the repo has been changed yet — this page is for choosing only.

A. Monochrome Ember AA large only

Violet removed outright. One accent hue, warm near-black neutrals. The most confident and the hardest to get wrong; violet is recoverable later.
